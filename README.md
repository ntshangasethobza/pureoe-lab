# Pureoe Lab staging storefront

Responsive static preview for the Pureoe Lab brand and catalogue. Built as a staging-only landing page and served by nginx on port 80 for Railway.

## Deploy
Railway builds the Dockerfile at the repository root. No secrets or database are required for this static preview.

## Important
This is not the full e-commerce/member/MLM application. Checkout, payments, authentication, member registration and commissions are disabled. Product names and indicative prices are placeholders pending supplier, ingredient, safety, pricing and legal verification. Do not accept orders or payments from this preview.
